# anti-backrooms-skill

`anti-backrooms` catches visual, spatial, and textual output that is locally plausible but globally wrong.

It is for UI, decks, diagrams, docs, PDFs, signage, booths, copy, and other user-facing artifacts, and equally for the surfaces that do not look like design work: a comment, a commit message, a name, a reply, a reusable instruction. Anywhere nonsensical wording, unsupported claims, wrong scale, broken hierarchy, impossible adjacency, repetition, leaked internal context, or a generic artifact shaped by one person makes the result feel uncanny.

It gives the agent a way to name and correct outputs that technically fit but still feel averaged, impossible, or detached from real human use.

`SKILL.md` contains the review method, operating behavior, correction patterns, and compact examples.
